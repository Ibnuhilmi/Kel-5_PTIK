# Sofa Shop - Website Toko Online Furniture (Kelompok 5 PTIK)

Website e-commerce katalog toko online sofa modern yang dikembangkan untuk memenuhi tugas besar mata kuliah Pengantar Teknologi Informasi dan Komunikasi (PTIK) - Kelompok 5.
repository ini dibuat untuk bisa bekerja sama dengan sesama tim kelompok 5 matakuliah PTIK 

## Fitur Utama Website
1. Multi-Page Architecture:
   - index.html: Halaman Beranda (Hero section, keunggulan, ulasan, preview produk unggulan).
   - katalog.html: Halaman Katalog Produk interaktif (Filter kategori, quick view modal).
   - tentang.html: Halaman Profil Perusahaan & Anggota Kelompok 5.
   - kontak.html: Form konsultasi interaktif & Informasi lokasi.
2. Estetika & Desain Clean:
   - Palette warna: Krem, Putih, Abu-abu, Hitam, dan aksen Warm Sand.
   - Tipografi elegan kombinasi Playfair Display dan Plus Jakarta Sans.
3. Animasi & Interaktivitas:
   - Scroll-triggered reveal animation.
   - Smooth hover scaling, shadow elevation, dan quick-view modal.
   - Mobile responsive navigation.
